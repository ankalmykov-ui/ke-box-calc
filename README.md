# KE | BOX CALC v2.0

Новая реализация KE | BOX CALC по техническому заданию v2.2 от 27.08.2026.

Эта ветка создана с нуля и не является продолжением кодовой базы v0.7–v0.9. На первом этапе в ней фиксируются только архитектура, каноническая модель данных, контракт расчётного варианта и границы реализации. Код приложения намеренно отсутствует.

## Источник истины

- «KE | BOX CALC — техническое задание v2.2» в Google Drive проекта;
- утверждённые формулы и версионируемые справочники;
- проверенные производственные параметры;
- паспортные данные оборудования;
- исторические техкарты — только как контрольные примеры.

## Неприкосновенные границы

- `main` и production v0.7.1 не изменяются;
- `v0.8-dev` и `v0.9-dev` сохраняются как история предыдущих подходов;
- разработка v2.0 ведётся в независимой ветке `v2-dev`;
- staging v2.0 использует отдельную базу и не имеет доступа на запись в production;
- перенос старого кода возможен только как отдельная проверенная реализация нового контракта, а не копированием старой архитектуры.
