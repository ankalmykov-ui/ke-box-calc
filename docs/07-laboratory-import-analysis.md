# Анализ лабораторной таблицы BCT

Источник: `Таблица лабораторные испытания 2026(2).xlsx`, получен 04.09.2026.
Исходный файл не изменяется и не включается в Git-репозиторий.

## 1. Состав файла

|---|---:|---:|---:|

Лист `Нормы по ТУ` содержит нормативные ECT и другие показатели марок. Лист

в нём есть записи 2025–2026 годов.

## 2. Пригодность для расчёта

Сильные стороны:

- все 104 записи BCT содержат композицию;
- 102 из 104 записей BCT содержат три размера короба;
- обнаружено 53 уникальных текстовых композиции с BCT;
- 17 композиций имеют два и более испытания, максимум — 13;
- фактический ECT заполнен в 1 191 строке и может расширить область прогноза;
- трёх- и пятислойные композиции записаны по отдельным слоям.

Ограничения:

- BCT есть только в 8,4% строк;
- числовое требование клиента есть только в 25 строках, из них 20 одновременно
  содержат BCT;
- отдельной колонки профиля нет; для большинства строк профиль можно вывести из
  суффикса заявленной марки `В`, `С` или `ВС`, но источник такого значения должен
  сохраняться как `derived`;
- в колонке среднего BCT встречаются серии измерений через `/`; импортёр должен
  хранить исходную строку и рассчитывать среднее;
- единица BCT не указана в заголовке. Диапазон 1457–4786 и запись
  «ВСТ не менее 2500 Н» подтверждают рабочую трактовку исходных значений как ньютонов;
  в базе они нормализуются в килоньютоны;
- в датах, наименованиях линий, марках и материалах есть разнородные записи;
- ширина рулона присутствует внутри текста материала и не должна входить в
  идентичность композиции по прочности.

## 3. Принятая модель BCT

1. Требуемый BCT и полученный BCT хранятся раздельно.
2. Числовое значение из `Требование клиента` становится порогом только после
   нормализации единиц и проверки строки.
3. Фактический BCT применяется напрямую при сопоставимых геометрии, профиле и
   нормализованной композиции.
4. При отсутствии прямого BCT допускается прогноз через исторический фактический
   ECT и калиброванную формулу. На 58 строках с полным набором полей первичная
   проверка дала корреляцию 0,826 и медианную абсолютную ошибку 11,8%. До
   производственного применения нужен консервативный нижний доверительный предел.
5. Запрошенная марка хранится справочно и не блокирует композицию другой марки,
   если нижняя оценка BCT не ниже требуемого порога.
6. Если требуемый BCT или надёжная оценка кандидата отсутствует, система показывает
   вариант как неполный и не называет его производственной рекомендацией.

## 4. Порядок импорта

1. Сопоставить колонки по заголовкам отдельно для каждого листа.
2. Исключить строки, содержащие только форматирование или норматив влажности.
3. Нормализовать дату, марку, профиль, размеры, линию и пять возможных слоёв.
4. Разобрать BCT на отдельные измерения, среднее в кН и исходное значение.
5. Сопоставить материал без включения ширины рулона в прочностную идентичность.
6. Показать отчёт: принято, требует классификации, пропущено, дубли.
7. Применить подтверждённую партию идемпотентно по контрольной сумме файла.
